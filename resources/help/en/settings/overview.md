# Settings

**Settings** is one window for the choices that apply to the whole application. Open it with the gear in the title strip. The pages are on the left, the fields of the selected page on the right.

![The Settings window on Graphic › Global](settings_window.en.png)

## Pages

| Page | What it holds |
|---|---|
| **Layout** | Which panels are shown, and opening the last project on startup. Panel switches act at once. |
| **Units** | Display units per quantity and the X axis unit of the project. See [Units](topic:units/intro). |
| **Graphic › Global** | Application theme and graph theme (below). |
| **Graphic › Graph Rendering** | Downsampling and drawing of curves. See [Graph Rendering](topic:settings/graph_defaults). |
| **Computation › Result Cache** | Compression and reuse of cached results. |
| **Maintenance** | Check for updates on startup, resets. See [Updates](topic:updates/intro). |
| **About Spectra** | Version and changelog. |

Type in **Search settings…** to keep only the pages that contain the word.

## Apply and Revert

Edits are a draft. **Apply** saves them and puts them to use; **Revert** discards them. A page with unapplied edits is shown in bold. **Close** asks what to do with edits still pending.

## Themes

- **Theme**: **Dark** or **Light** look of the whole application.
- **Graph theme**: look of the graph area only. **Follow theme** uses the application theme; **Dark** or **Light** keeps graphs in one look whatever the application theme is.

Both apply after the application is restarted. A theme changes colours only; it does not change any result.
