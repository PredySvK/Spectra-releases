## 📊 Evaluation: Top-N maxima

<b>Top-N maxima</b> returns the N highest <b>Local maxima</b> of each visible curve, ranked by height. A Local maximum is a point that stands clear of its neighbours by a minimum distance along the X axis and a minimum prominence in dB -- not the single overall [Max](topic:evaluation/max) (that is a separate, parameter-free Evaluation), and not "dominant maxima" (which would rank by prominence instead of height; see [Dominant orders](topic:evaluation/dominant_orders)).

- <b>N:</b> How many maxima to return per curve, at most. A curve with fewer qualifying humps than N simply gives fewer rows -- never padded to N, and never a "&mdash;" dash row like Max would give for an empty curve. Default 3.
- <b>Min distance:</b> The minimum separation between two selected maxima, measured in the curve's own X-axis unit ([units](topic:units/intro): RPM, Hz or s -- not a fraction). "Auto" uses 5% of that curve's own axis range, so a dock mixing order cuts and Overall Level curves still gets a sensible default for each. Set an explicit number to use the same axis-unit distance for every curve in the table.
- <b>Min prominence:</b> How far a maximum must stand out above the valley toward its higher neighbour, in amplitude dB. Computed from the square root of power per bin for spectra, so 3 dB means the same thing on every curve kind, and does not depend on the [RMS/Peak switch](topic:shared/amplitude_format) or a channel's sensitivity (scaling every sample by the same factor shifts every dB value by the same constant, leaving the difference -- and therefore the prominence -- unchanged). Default 3 dB.
- <b>Wavy single hump:</b> Small ripple riding on top of one hump gives exactly one maximum -- the ripple's own bumps sit less than the minimum prominence above the shared valley next to the true top, so only the top qualifies.
- <b>Two humps:</b> Two humps separated by a deep-enough valley and far enough apart on the X axis give two maxima, the taller one first.
- <b>Range edge:</b> A point at either end of the curve counts as a Local maximum if it clears the prominence and distance rules on its one existing side -- durability runs where the level keeps climbing to the end of the sweep are exactly the case this matters for. Edge maxima carry <b>Yes</b> in the <b>Edge</b> column.
- <b>Almost flat curve:</b> If every sample sits within the minimum prominence of every other, Top-N maxima returns no rows at all for that curve -- while Max, which has no prominence to clear, still returns its one highest point.
- <b>NaN and zero samples:</b> Both are treated as -&infin; dB. They can never be selected as a maximum themselves, but they always count as a valley deep enough to satisfy any prominence requirement on their side of a neighbouring peak.
- <b>Edge column:</b> Marks a Single value sitting at either end of its curve's valid data with <b>Yes</b> -- the first or last sample that is not NaN. An order cut whose order climbs above Nyquist at high RPM (or sits below the resolution at low RPM) ends in NaN samples, so a maximum on the last valid sample is flagged too: the real level may keep rising beyond the range. Shown for every Evaluation, not only Top-N maxima -- Max can also land on an edge sample.
- <b>Amplitude, Format, Units, Sorting, Copy/Export, Columns&hellip;, Respect Trace filter:</b> Same as the [Max Evaluation](topic:evaluation/max) (see its help topic) -- Top-N maxima shares the same table, display switches and toolbar.
